点名啦 V1.1 使用说明
=================

一、开始点名
1. 在左上角选择班级。
2. 点击“开始点名”，姓名会快速轮换并自动减速公布结果。
3. 同一轮内不会重复点到已经选中的学生。
4. 点击“重置”可开始新一轮，原有历史记录不会被删除。

二、班级与名单
点击顶部“名单”，可以：
- 新建、改名、复制或删除班级；
- 每行输入一个姓名；
- 直接粘贴 Excel 中的一列姓名；
- 导入 TXT 或 CSV 名单。

名单保存在程序旁的“班级名单.json”中，修改后自动保存。程序升级时请保留这个文件。

三、点名记录
每次正式点中学生后，程序会自动保存时间、班级和姓名。
点击顶部“记录”，可以逐条勾选历史记录，也可以点击第一列表头的总勾选框进行全选或全不选。
“删除所选”只删除历史记录，不改变当前轮次的点名进度；“撤销上次”用于纠正最近一次有效点名；“导出所选”只导出已经勾选的记录。
导出的 CSV 使用中文 Excel 可直接识别的 UTF-8 格式。

四、背景音乐
点击顶部“音乐”，可以开启或关闭音乐、选择曲目、调整音量、试听和添加音乐。
支持 MP3、WAV、WMA。“欢乐节奏”“紧张冲刺”“轻快活泼”三首 CC0 音乐已封装在 EXE 中，首次运行会自动释放到 music 文件夹。“好运来”作为原项目的个人音乐保留在外部，换电脑时需单独复制。来源与授权见“音乐授权说明.md”。

五、课堂显示
- 班级、名单、记录、音乐、迷你模式和窗口按钮集中在同一条顶栏。
- “窗口置顶”可让点名啦显示在 PowerPoint 上方。
- “迷你模式”适合播放课件时使用。切回 PPT 后窗口会自动变为半透明，鼠标移入或开始点名时恢复清晰。
- 最终姓名在迷你窗口保留 20 秒，随后变为浅色“准备点名”；主界面中的结果不受影响。
- 常见班级的全部姓名会自动调整列数与卡片大小，不显示名单滚动条。
- 点击“—”会按 Windows 标准方式最小化到任务栏。
- 点击“×”不会退出程序，而是隐藏到右下角系统托盘。
- 双击托盘图标可恢复主界面；右键菜单可打开主界面、进入迷你模式、设置开机自启动或退出。
- 开机自启动仅对当前 Windows 用户生效，开机后静默进入托盘；再次点击菜单可关闭。
- 程序只允许一个实例运行，重复双击 EXE 会唤醒已经运行的主界面。

六、快捷键
空格：开始点名；滚动时按空格可提前进入减速阶段。
Ctrl + Z：撤销最近一次有效点名。
Ctrl + T：切换窗口置顶。
Ctrl + M：进入或退出迷你模式。

七、数据文件
班级名单.json：班级、姓名和当前轮次。
点名历史.json：全部点名历史。
settings.json：置顶、音乐、音量、最近班级和迷你窗口位置等设置。
上述名单和历史在保存时会保留一份 .bak 备份，以便文件异常时恢复。

八、程序文件
点名啦 V1.1.exe：点名啦 V1.1 主程序。
点名啦V1.0.cs、点名啦数据与窗口.cs：源代码。
构建V1.ps1：重新生成 EXE 的构建脚本。
assets 文件夹：应用图标的 PNG 与 Windows ICO 文件。
点名啦.manifest：Windows 权限与高 DPI 显示设置。

旧版构建和解包缓存已从工作目录整理移除；如需追溯，可从 Git 历史恢复。
