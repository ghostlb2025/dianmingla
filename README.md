# 点名啦

“点名啦”是一款面向课堂场景的简洁随机点名工具。软件支持多班级名单管理、一轮内不重复点名、历史记录与 CSV 导出、窗口置顶、迷你模式、系统托盘以及可选背景音乐。

## 下载

[下载最新版“点名啦”](https://github.com/ghostlb2025/dianmingla/releases/latest)

当前稳定版本为 v1.0.1。下载 Windows 单文件程序后即可运行，无需安装。

## 主要特点

- 920 × 500 固定紧凑窗口，常见班级名单无需滚动即可完整显示。
- 280 × 150 迷你窗口，适合上课时与 PPT 同时显示。
- 新建、复制、重命名和删除班级，支持粘贴或导入 TXT/CSV 名单。
- 每轮随机点名不重复，支持重置、撤销和历史记录导出。
- 点击关闭按钮后隐藏到系统托盘，只有托盘菜单“退出”才会结束程序。
- 内嵌 3 首 CC0 背景音乐，也可以添加本地 MP3、WAV 或 WMA。
- 完全离线运行，不登录、不上传学生数据。

## 示例数据

首次运行会创建 3 个虚构示例班：

- 示例一班：36 人；
- 示例二班：49 人；
- 示例三班：24 人。

示例姓名采用“甲同学01”“乙同学01”等明确的演示标识，不对应任何真实学生。

## 构建与运行

在 Windows 10 或 Windows 11 上运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\构建V1.ps1
```

构建完成后会在项目根目录生成 `点名啦.exe`。程序基于系统自带的 .NET Framework 4.x，无需额外安装项目依赖。

## 本地数据与隐私

程序运行后会在 EXE 旁生成 `班级名单.json`、`点名历史.json` 和 `settings.json`。这些文件以及 `人员名单/` 目录均已加入 `.gitignore`，不得提交到公开仓库。

公开发布前请按《公开发布检查清单.md》进行检查。当前私人开发仓库曾包含真实名单，因此不能直接公开其既有 Git 历史，应从清理后的文件重新创建一个没有旧提交的新仓库。
